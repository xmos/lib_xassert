# XMOS Library Agent Guidance

Read this repository's README, documentation, examples, build configuration
and repository-specific guidance below before making changes.

## Central XMOS Guidance

Consult the [XMOS agent instructions](https://github.com/xmos/xskills/blob/main/AGENTS.md)
and relevant skills. Use the xskills baseline specified below, if any;
otherwise use the latest approved release on `main`.

Access the guidance through an installed copy or the referenced release.
A link alone does not install or load skills; see the
[setup instructions](https://github.com/xmos/xskills/blob/main/README.rst)
for access and installation options.

Repository-specific hardware, compatibility and legacy requirements take
precedence over general recommendations. Preserve existing APIs and conventions
unless migration is requested.

If central guidance is inaccessible, continue using this repository's
documentation and identify any material verification gaps.
